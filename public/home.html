That SEO Agent
MCP server · running locally
Read-only SEO analysis

An instrument, not a dashboard.

This server is running on your machine and listening on loopback. Point an MCP client at the endpoint below and its Tools become available to your agent. Nothing here writes to a site, a sitemap, or a Google property.

Endpoint http://127.0.0.1:3737/mcp
Tools 55 SEO analysis capabilities
Prompts 3 Workflows that chain them
Playbooks 3 Readable under seo://
Two halves

What works right now, and what needs a login

No credentials at all

Everything named seo_*, plus crawl_site. These read a site's public surface and work on any domain, including ones you do not own. They need no account, no key and no database.

Your own Google data

gsc_*, ga4_* and run_site_audit read your Search Console and Analytics through an OAuth client you create. Until you log in they stay listed and say so, rather than disappearing.

Connecting

Point a client at it

{
  "mcpServers": {
    "thatseoagent": {
      "url": "http://127.0.0.1:3737/mcp"
    }
  }
}

There is no key and no token. The server binds loopback only and refuses cross-origin requests, so a web page cannot drive your Tools.

How it reports

What this server will not do

  • A check that could not run is never reported as a check that passed.
  • An absence of findings is an absence in the rows read, not a fact about the site.
  • A threshold that is ours is named as ours where it is applied.
  • A Tool that cannot do its whole job refuses and says what to configure, rather than returning a smaller result that looks complete.
  • The AI-visibility and GEO scores are directional readings of visible signals, never measurements of how any AI system behaves.
